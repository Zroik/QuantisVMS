## 1. Verified fixes (do not re-litigate)

Confirmed genuinely fixed against current code — this is a strong remediation pass:

- **Fail-closed secrets**: compose `${VAR:?}` for all six secrets; `.env.example` leaves them blank; `config/validate.ts:8-12` denylists public defaults; recorder `assertProdSecrets()`.
- **MediaMTX auth hook**: validates `action`/`path`, restricts `publish` to internal secret/admin, constant-time compare, returns 403 (not 500) on misconfig (`routes/internal.ts:22-31,65-93`); control API excluded in `mediamtx.yml`.
- **JWT type separation**: access/refresh/media-ticket `typ`; refresh rejected as access; refresh no longer returned in JSON; cookie-only refresh (`auth/service.ts`, `auth/routes.ts`).
- **Password change** requires the current password and revokes refresh JTIs.
- **Credential crypto**: AES-256-GCM([iv|tag|ct]), refuses non-32-byte and all-zero keys; envelope format matches the RTSP proxy.
- **Path-traversal defense** (realpath + `/data` containment + bounded cache); stream/download have error + `close` handlers; Range works.
- **Honest telemetry**: `/api/stats` computes savings only from `COMPLETED` rows with non-zero compressed size; real queue counts; `null` when GPU/RAM unknown; watermark fails **closed** on statfs error with a critical alert.
- **Guarded raw deletion**: requires `status='COMPLETED' AND quality_gate_met=1 AND compressed_path IS NOT NULL AND raw_deleted_at IS NULL` + flag + grace + file existence.
- **State machine**: one function, `SELECT … FOR UPDATE` in a transaction; `COMPLETED` cannot be downgraded; `RECORDING→SKIPPED` legalized.
- **VMAF correctness**: `[dist]` first / `[ref]` second; watchdog `max(180s, 6×sample)`; CUDA→CPU fallback; frame-count check accounts for CPU `n_subsample`; p25 from per-frame values via numpy-linear interpolation.
- **Consolidator now rebases activity-window offsets and reassigns detection events / probe logs** (the remaining gap is validation — finding 4).
- **Detection wire contract** is canonical end-to-end (`{cls,conf,x1..y2}` produced, normalized in the store, drawn by `BboxOverlay`).
- **`camera:changed`** carries `enabled`/`rtsp_changed`; recorder/AI re-check DB `enabled` and skip metadata-only restarts; child slices excluded.
- **PyAV** uses a version-tolerant `FFmpegError` alias; `is_connected=False` in `finally`; clean EOF reconnects with backoff.
- **Recorder resilience**: exit code/signal/stderr logged, spawn-error backoff, restart in `finally`, safe Redis publishes, per-camera lock, bounded `stop()`, finalize guarded `WHERE status='RECORDING'`.
- **All 6 Dockerfiles run non-root**; prod compose no longer bind-mounts `dist`/`src`; nginx has CSP/HSTS, upgrade map, `/readyz` proxy, and the HLS redirect preserves host+port.

## 2. Backend (`apps/api-server`)

### 2.1 Data integrity & transcode correctness

- **BE-01 (High) — Consolidator deletes originals without validating the merge.** `consolidator.ts:287-308,411-425`. Accepts `exitCode=0` + size > 1 KB; `probeDurationSec` returns `0` on ffprobe failure and is never checked against the sum; no decode test; then `unlink`s the source segments. A truncated merge can destroy the only copy. **Fix:** require `duration > 0` within tolerance of `Σ segment.duration_sec`, run a bounded `ffmpeg -v error -i merged -f null -`, and abort (keep originals) otherwise. *(still open: BE-S8)*
- **BE-02 (High) — §8.6 verification is incomplete.** `pipeline.ts:678-753`. Only `chunkResults[0].sampleStartSec` is re-checked from the final file; no per-chunk re-check, no compressed-vs-raw frame-count parity (±2×chunks), no bounded `cq−2` re-encode. **Fix:** loop the re-check over all chunks, add parity, implement the retry. *(partial: BE-S7/OPS-4)*
- **BE-03 (High) — Transition-then-enqueue strands `QUEUED` rows.** `worker.ts:225-250`, `watermark.ts:115-129`, `recordings.ts:552-569`: `transitionRecordingStatus(...QUEUED)` runs before `queue.add(...)`, and the `catch` is silent. If `add` fails, the row is `QUEUED` with no job; the scheduler only scans `RAW` and nothing reclaims it. **Fix:** enqueue first with `jobId=rec-{id}`, transition after; on failure revert to `RAW` + alert; add an orphan-`QUEUED` reconciler. *(still open: X-12)*
- **BE-04 (High) — Credential masking leaks password tails.** `credentials.ts:117-137`. `maskRtspUrl` uses `/:\/\/[^:]+:[^@]+@/` and `extractRtspHost` uses `split("@")[1]`; a password containing `@` leaves `ss@host` visible and stores part of the password in `rtsp_host` (returned to every authenticated user). *(verified)* **Fix:** parse with `new URL()` and clear userinfo.
- **BE-05 (Medium) — CPU VMAF fallback compares mismatched formats.** Probe/encode writes `p010le` (10-bit); the CUDA path normalizes with `format=yuv420p` but the CPU fallback filtergraph (`vmaf/runner.ts:169`) does not, so the rescue path can fail/mis-score. **Fix:** add `format=yuv420p` to both inputs (or write 8-bit samples per §9.3). *(E7)*
- **BE-06 (Medium) — Window/coverage math + `PROBE_SAMPLE_SEC` default drift.** `pipeline.ts:265-267` defaults `probeSampleSec=10` while spec §6.5 says `20`; `window-selection.ts:62-69` computes coverage from `ACTIVITY_WINDOW_SEC` rather than the sample duration, so `ai_peak`↔`blind_fallback` can flip. **Fix:** one shared window constant asserted at startup; align to 20. *(partial: X-08)*
- **BE-07 (Medium) — `static_cq_cache` is never written**, so the `static_cache` fast path can never activate (every quiet chunk re-probes). `pipeline.ts` (no write), read at `cameras.ts:128`, `pipeline.ts:398`. **Fix:** persist the chosen CQ + timestamp after a static `blind_mid` probe. *(new)*
- **BE-08 (Medium) — JWT refresh reuse-detection revokes all sessions on concurrent refresh.** `auth/service.ts:245-258`: the losing request deletes every JTI, including the winner's (full re-login; client single-flight doesn't cover multi-tab). **Fix:** small server-side grace window / per-user refresh mutex.
- **BE-09 (Low) — `compressed_path` can point at a deleted `.partial` on failure.** `pipeline.ts:629-631,826-848`; only the SKIPPED branch nulls it. **Fix:** null path/size on the failure path too.
- **BE-10 (Low) — `attempts` incremented for terminal rows before the guarded transition.** `worker.ts:70-88`. **Fix:** move the increment into transition metadata.

### 2.2 Security, operability, performance

- **BE-11 (High) — Redis client reliability.** `redis/client.ts:12-42`: no `.on("error")`, `maxRetriesPerRequest: null` (commands queue forever; the rate-limit catch never fires). **Fix:** finite retries/`commandTimeout`, attach an error handler, fail **closed** for `/auth/*`. *(still open: BE-S9/BE-17)*
- **BE-12 (Medium) — No `trust proxy`.** `app.ts:16-27`, `auth/middleware.ts:103-109`: behind nginx every client shares the proxy IP, so 5 failed logins lock out all users. **Fix:** `app.set("trust proxy", 1)`, forward `X-Forwarded-For`, key login by `username+ip`. *(still open: X-10)*
- **BE-13 (Medium) — ONVIF returns credential-bearing URIs and allows viewer-triggered SSRF.** `routes/onvif.ts:47-134`, `onvif/client.ts:278-297`: `verify` returns a `primaryStreamUri` with injected credentials; `discover` is viewer-readable and probes arbitrary `xaddr`; ping/NTP accept arbitrary hosts. **Fix:** mask/short-lived URIs; make discovery admin-only + rate-limited; add a private-range denylist. *(still open: BE-S12/S13/BE-10)*
- **BE-14 (Medium) — Missing `rtsps://` validation.** `routes/cameras.ts:29,46` rejects `rtsps://`; also accepts an empty host. **Fix:** `/^rtsps?:\/\//` + `new URL()` host check. *(still open: BE-S21)*
- **BE-15 (Medium) — Unbounded/N+1/recursive work in hot loops.** `watermark.ts:110-129` (no `LIMIT`), `priority.ts:59-90` (per-job query per tick), `stats.ts:15-48` (recursive `getDirSize` every 15 s), `recordings.ts:169-191` (2 filesystem stats per row). **Fix:** batch/cap, one aggregate priority query + batched `changePriority`, cache storage longer, expose `has_raw/has_compressed` from indexed columns. *(still open: BE-14/BE-08)*
- **BE-16 (Medium) — No graceful shutdown in the API.** `index.ts:23-141`: no SIGTERM/SIGINT handler; `closeRedisClients`/`closeDbPool` are exported but never called. **Fix:** drain HTTP → socket → Redis/DB on signal. *(§13)*
- **BE-17 (Medium) — `join:camera` has no per-camera authorization.** `sockets/gateway.ts:61-94`: any authenticated viewer joins any camera room. **Fix:** per-camera ACL or document the "all viewers see all cameras" decision. *(partial: BE-03)*
- **BE-18 (Low) — Internal-field exposure / per-request decryption.** `recordings.ts:249-253` returns raw/compressed paths on the detail route (the list masks them); `cameras.ts:78-88` decrypts every credential blob on every `GET /cameras`. **Fix:** mask paths / return flags; avoid decrypting for a masked URL. *(still open: X-13)*
- **BE-19 (Low) — Admin password printed in plaintext at startup.** `index.ts:66-72`. **Fix:** write a one-time password to a root-only file or require `INITIAL_ADMIN_PASSWORD`. *(new)*
- **BE-20 (Low) — Migrator false atomicity + naive `;` splitting.** `db/migrator.ts:20-30,92-110`. DDL isn't transactional in MySQL; splitting breaks on `;` inside strings. **Fix:** one statement per migration, checksums, drop the transaction pretense. *(still open: BE-13)*
- **BE-21 (Low) — `syncCameraSlices` mutates DB/Redis/MediaMTX outside a transaction** and cascade-deletes children while media files remain. `cameras.ts:144-252`. **Fix:** one DB transaction + deferred side effects; soft-delete slices. *(still open: BE-S3/X-01)*
- **BE-22 (Low) — No `/api/vmaf/probes` (spec §6.4); two divergent probe endpoints.** `events.ts:57-72` (`/api/events/probes`), `stats.ts:472` (`/api/stats/vmaf-probes`). **Fix:** add the spec route (or alias) and document canonical. *(new spec-deviation)*
- **BE-23 (Low) — Config defaults advertise fiction.** `routes/config.ts:12-86`: `YOLO26n`, `TensorRT 10.x`, `httpPort 5173`, `whepPort 8555`, CORS `5173`. **Fix:** derive from env/runtime; correct ports. *(still open: OPS-7/BE-18)*
- **BE-24 (Low) — Dead code / stubs**: `recordAuditLog` never called (`config.ts:125`); `lint` is `tsc`; `verify-gpu` is `echo`; `io.to("system")` emits to a room nobody joins; `pino` is a dependency but unused. **Fix:** remove or wire. *(still open: BE-16/X-I5)*
